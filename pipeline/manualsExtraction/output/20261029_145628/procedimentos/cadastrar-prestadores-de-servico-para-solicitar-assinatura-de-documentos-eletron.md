# Cadastrar Prestadores de Serviço para solicitar assinatura  de  Documentos eletrônicos

Este tutorial possui 2 etapas

|  |  |
| --- | --- |
| Etapa cadastro de prestadores de serviços | Para os Cadastradores habilitados (Protocolos Campi) |
| Etapa criação de documentos e solicitação de assinatura | Para Setores que criam documentos para serem assinados pelos prestadores de serviços |

Perfil de Prestadores de Serviço

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| Estagiários e Terceirizados | | | | Setor no SUAP: setor ao qual se vinculam | |
| Representantes legais de empresas (Pessoa Jurídica) | | | | Setor no SUAP: SETOR - EXTERNO-IFPI | |
| Egressos\* (que necessitam assinar atas de Comissões, Comitês e Conselhos) | | | | Setor no SUAP: SETOR - EXTERNO-IFPI | |

Etapa cadastro de prestadores de serviços:

ATENÇÃO: AS SOLICITAÇÕES DE INCLUSÃO DE USUÁRIOS EXTERNOS PARA ASSINATURA DE DOCUMENTOS SERÁ PELA CENTRAL DE SERVIÇOS https://suap.ifpi.edu.br/centralservicos/listar\_area\_servico/, selecione a aba criada para essa finalidade.

1º Passo: No menu lateral, acesse a opção ADMINISTRAÇÃO e selecione Cadastros. Em seguida, clique em Prestadores de Serviço.

![captura de tela](https://lh3.googleusercontent.com/5kQOFyiSJyC14kbVchUF2RBD3iFtwjpHwqDkHR0bxk7AMgXKPe3mGiyhh35oORk2Hs-41HHhxp93l_O20ulzFnDc6oYAGbi45a2FasVW70hazIzGR5Uhp2VC6PIFmxrJ3ZX5IXjTaO6Jbc5pG76VoK4)

2º Passo: Na tela de Prestadores de Serviço, clique no botão Adicionar Prestadores de serviço, localizado no canto superior direito da página. A URL para acessar essa tela é  https://suap.ifpi.edu.br/admin/comum/prestadorservico/

![captura de tela](https://lh6.googleusercontent.com/1lHUZ7FwmCGLEwWY2xKM9K7hYNEfMS0OPf1hZ5OI0gDhUARMuINb80qrDupxsVB3MAVCP9kce0yxikHVn9g4vhsPS_2f3yJyZ2DzsmUMFCl9t7jx-G4troN9jkumEIQJl79sIvHvmPQa1HcwBTIMLzY)

3º Passo A (Estagiários e Terceirizados): Na tela de cadastro, preencha os dados do Prestador de Serviço solicitados. No campo "Nome de Registro", insira o nome do prestador. É importante lembrar que os campos CPF, Sexo, Nacionalidade e Setor são obrigatórios.

![captura de tela](https://lh6.googleusercontent.com/a2DZcobnnGUvuMW7oS7D37fRZYxf5ElrOsXzlHsr74oqBLOSW74IsDwEu_VRrNXrUO6aCp89n5wphZ1TJGgqu6MJCiscEW9EojQIOJ6rvWOWhZk2u8SFc2DIO51Ihg42ECflYgdwxV7bNtNzl1w_c_Y)

3.1.a - No campo "Setor", selecione o setor em que o prestador de serviço ficará lotado. No campo "E-mail Secundário", adicione o e-mail secundário do prestador para que, no primeiro acesso ao Suap, ele possa solicitar a senha de acesso. Após preencher todos os campos obrigatórios, clique em "Salvar".

![captura de tela](https://lh4.googleusercontent.com/rGmRn8_HQYPBxeQ7pL6YtjLC2tffhxWuPwqvjoLyzJ4wdBfB32jOa1k6oV2j5_YtZ0MEfl_xPBJp40VXVsuXB7f1wViLgQHTEHOUxCLpuLMEpfxCbCWGwHVCoXrw9SUWQ5uJ6YySJcs71iStguSofjM)

3º Passo B (para Representantes de Pessoas Jurídicas, Autônomos, Pessoas Física e Egressos): Na tela de cadastro, preencha os dados do Prestador de Serviço solicitados. No campo "Nome de Registro", insira o nome do prestador. É importante lembrar que os campos CPF, Sexo, Nacionalidade e Setor são obrigatórios.

![captura de tela](https://lh6.googleusercontent.com/a2DZcobnnGUvuMW7oS7D37fRZYxf5ElrOsXzlHsr74oqBLOSW74IsDwEu_VRrNXrUO6aCp89n5wphZ1TJGgqu6MJCiscEW9EojQIOJ6rvWOWhZk2u8SFc2DIO51Ihg42ECflYgdwxV7bNtNzl1w_c_Y)

3.1.b - No campo "Setor", selecione o setor "SETOR EXTERNO-IFPI", pois não há um setor específico para esses tipos de prestadores de serviço. No campo "E-mail Secundário", adicione o e-mail secundário do prestador para que, no primeiro acesso ao Suap, ele possa solicitar a senha de acesso. Após preencher todos os campos obrigatórios, clique em "Salvar".

![captura de tela](https://lh3.googleusercontent.com/2qRHNj1L1DUePl41MGc-AQdMbcbQ7Yqa6LbsIHQTUVcLWpZhOiJD501LTaQeNpna1SAfRmPG0ETi8WF-NE0Kgd0_-0QCBMQD8Z0i0nsF_i0LLBkecdUxEVAk76o7T2-i4xvTBgyLdU9qqvz6_up0JDM)

4º Passo: Para adicionar o setor e a função do prestador, consulte o nome do mesmo na lista de prestadores cadastrados. Você pode fazer isso acessando a opção "Acesse o Cadastro" na barra central acima ou clicando na lupa ao lado do lápis.

![captura de tela](https://lh5.googleusercontent.com/eE1zw9n2gYZ_eGhQgsW7iyISjy3N2VoVq4fgtXljTU0gxCIjs8q5_XGuqbIvJGyLp2dUxXTX7pHWMd1KnMK2B4EEO92NUbLv1Yddx3gZZDRwsRa9Iq6xc6K7vFpwXfUOoLhcCzCmg31gLkPqH5kOPgw)

5º Passo: Na tela com os dados do prestador de serviço, clique no botão "Vincular Ocupação".

![captura de tela](https://lh5.googleusercontent.com/akLl1WOpMCLmRx-lAoOb4OzoWDzj0_qiMtT1svvwPBoQxSVoig7GknTfYctXQhqwX_tFiM7e-GuvBabYNR_zhoxsEyJvEAO4NDXc6ZE8VSVcsU6ZCPNm2nzJYDKRk9qY1yky8O2KIP_ifm8lpnvvU2U)

6º Passo: Preencha os campos de ocupação, nome da empresa, data de início e término do contrato, e o Setor Suap. É importante lembrar que todos esses campos são obrigatórios. Após preencher os dados corretamente, clique em "Salvar".

![captura de tela](https://lh3.googleusercontent.com/5OLSkCVsqR8X-iZReebhpgC9boL9XS7q7Ee2d0Vw9nV26N0Evz3HEWxBx_47q5qTCwQFFS-REOsJW12AaungTG4jmlPNaUgqL2eB6FEFYN66-RCO5T-mhdM9WHVsQslvQ3FLJB0lPee6lrer_AUG_7w)

OBSERVAÇÕES IMPORTANTES:

Quando for “Vincular Ocupação” deverá ser vinculado a uma Pessoa Jurídica. Exemplos:

- Representante da Construtora - Nome da empresa Pessoa Jurídica;
- Autônomo/Pessoa Física -  EXCEPCIONALMENTE, até que seja regularizado a pendência, a pessoa Jurídica será “Instituto Federal de Educação, Ciência e Tecnologia do Piauí - Reitoria (10806496000149)”.
- Egressos: EXCEPCIONALMENTE, até que seja regularizado a pendência, a pessoa Jurídica será “Instituto Federal de Educação, Ciência e Tecnologia do Piauí - Reitoria (10806496000149)”.

Etapa criação de documentos e solicitação de assinatura

ATENÇÃO: OS SETORES QUE NECESSITAM DE DOCUMENTOS ELETRÔNICOS COM ASSINATURA DE USUÁRIOS EXTERNOS, DEVEM REALIZAR OS PROCEDIMENTOS. CONSULTAR AS ROTINAS ESPECÍFICAS, DE QUEM PODERÁ ENCAMINHAR O DOCUMENTO PARA ASSINATURA.

1º Passo: Agora, crie um documento eletrônico para que o prestador de serviço possa assiná-lo. É importante lembrar que todos os campos são obrigatórios e, ao finalizar a criação do documento, clique em "Salvar".

![captura de tela](https://lh6.googleusercontent.com/jA34areRIHo4wzxO8lmYHhzTta-y8O9YigqoVUi0f2LlgtG4djpeQB8RLLwC5BBeK5oywUn8AsPQkhISGAJMnI7v1cR0aEGKs3emuA7JLExbguxi7_hLZiMII86ibpjU1JInluCJ6TYNajZFxV9Bb0g)

2º Passo: Após criar, preencher e editar o documento, clique em "Concluir".

![captura de tela](https://lh6.googleusercontent.com/2m_1Q-JISrJwK5yCbzaVVgIu6CcBRpEaYvTcYX69zFFw86egVzd2s2x-mUCJbNdNbpjsfWgR5FIVicyq8QWlOpz9lU6sV2fegjqdqDnaguWZRyNgb46eXov4Swz90TIx5CW3VoO4W1PiL-iKbKpfmvI)

3º Passo: Na próxima tela, clique em "Solicitar" e, em seguida, em "Assinatura".

![captura de tela](https://lh5.googleusercontent.com/4AQ2gC36-jwhIL139q6nLd80W36joTGVspLQ-ScHvyojjPXola7gdTRtWUD7oHB6I0M4U9DB3cHNBVDbcBXJA3pPAhxgTk-ojWeeltzyY7J9bcOvnxHAuIHzf-2Ab30Wa6W5rC_AMmHFXSHI1zIqxf0)

4º Passo: No campo "Solicitação Principal - Pessoa\*", procure pelo nome do prestador de serviço que irá assinar o documento e clique em "Enviar solicitações".

![captura de tela](https://lh5.googleusercontent.com/KCItx2HHdjiRwEVM8_IFlcLLWjjmRCXVt57EuP-MSbEP_JQURj8K0sADGI6V3iwUcQzCvsQd1wYDb21_67x2be12P6XSrBN68JrakS73wfVta81T_ky6X7bi5_C_Hz6aOytqakVqI2X6SCG1nTdxJ64)

Observação: Caso o nome do prestador de serviço não apareça, verifique se ele foi cadastrado corretamente como prestador de serviço no módulo de administração.

Importante: em caso de dúvidas/problemas de acesso entrar em contato através da CENTRAL DE SERVIÇOS.

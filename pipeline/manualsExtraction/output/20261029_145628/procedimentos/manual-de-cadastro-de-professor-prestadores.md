# Manual de Cadastro de Professor Prestadores

> Informação: Objetivo: Este manual tem como objetivo orientar os usuários através do processo de cadastro de professores prestadores no SUAP, fornecendo instruções detalhadas e visuais para cada etapa do procedimento.

> Dica: Descrição do Processo: O cadastro de professores prestadores é um processo essencial para o gerenciamento de profissionais externos que prestarão serviços educacionais. Este procedimento garante que todas as informações necessárias sejam coletadas e organizadas de forma adequada no SUAP.

==========================================================================================================

### **1º PASSO** - Busca no Menu Principal

**Na tela principal do SUAP, no canto superior direito no campo "Busca menu" , o servidor irá digitar "Professor" e em Ensino clicar no menu Professor.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-07/2SMPBXpX4MHfLDCI-captura-de-tela-de-2025-07-18-16-02-09.png)

> Atenção: Descrição: Utilize a ferramenta de busca para localizar rapidamente o menu Professor dentro da seção Ensino.

**-----------------------------------------------------------------------------------------------------------------------------------**

### **2º PASSO** - Adicionar Professor de Serviço:

**Na tela seguinte, o servidor vai clicar no botão "Adicionar Professor de Serviço" que fica no canto superior esquerdo.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-07/czrn72rGeM9m0MBn-captura-de-tela-de-2025-07-18-15-08-03.png)

> Atenção: Descrição: Este botão dará acesso ao formulário de cadastro do novo professor prestador.

**-----------------------------------------------------------------------------------------------------------------------------------**

### **3º PASSO** - Preenchimento dos Dados Pessoais

**Na tela "Adicionar Professor Prestador de Serviço" , o servidor vai cadastrar o docente prestador com os dados obrigatórios como nome, nacionalidade, sexo e naturalidade.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-07/LR5tJ1cGG3DdnIK3-captura-de-tela-de-2025-07-18-15-24-15.png)

> Atenção: Descrição: Preencha todos os campos obrigatórios relacionados às informações pessoais do professor prestador.

**-----------------------------------------------------------------------------------------------------------------------------------**

### **4º PASSO** - Preenchimento dos Dados Complementares

**Na tela "Adicionar Professor Prestador de Serviço" , logo mais abaixo, o servidor vai cadastrar também os dados de contatos, dados do professor e dados da formação. Ao final, clique no botão "Salvar" .**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-07/KHNF8szhM3cKJTXT-captura-de-tela-de-2025-07-18-15-25-36.png)

> Atenção: Descrição: Complete o cadastro com informações de contato, dados profissionais e formação acadêmica antes de salvar.

**-----------------------------------------------------------------------------------------------------------------------------------**

### **5º PASSO** - Cadastro Concluído

**Após o salvamento, o cadastro do Professor Prestador estará concluído, faltando apenas cadastrar o setor para que ele possa ter acesso às demais funcionalidades.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-07/9rhU4IaYsDFzPxwf-captura-de-tela-de-2025-07-18-15-32-51.png)

> Atenção: Descrição: O sistema confirmará o cadastro realizado. O próximo passo será vincular o professor a um setor.

**-----------------------------------------------------------------------------------------------------------------------------------**

### **6º PASSO** - Acesso aos Usuários Externos

**Para fazer o vínculo ao setor, o servidor irá buscar no menu por "Usuários Externos" e clicar no menu de Usuários Externos.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-07/idduBztvRaKlrtRP-captura-de-tela-de-2025-07-18-15-18-58.png)

> Atenção: Descrição: Acesse o menu de usuários externos para vincular o professor prestador a um setor específico.

**-----------------------------------------------------------------------------------------------------------------------------------**

### **7º PASSO** - Consulta e Vinculação

**O servidor vai consultar o CPF no "Filtro de texto" do Professor Prestador e clicar no botão "Vincular ocupação" .**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-07/8RtSgEy2o7rk4C0E-captura-de-tela-de-2025-07-18-15-30-10.png)

> Atenção: Descrição: Utilize o filtro de texto para localizar o professor cadastrado através do CPF e iniciar o processo de vinculação.

**-----------------------------------------------------------------------------------------------------------------------------------**

### **8º PASSO** - Configuração da Ocupação

**Na tela "Vincular Ocupação do Professor Prestador" , o servidor vai inserir os dados de ocupação:**

- **Ocupação: Outros**
- **Pessoa jurídica: Campo que ele vai estar associado**
- **Data de início e fim: Período que ele vai realizar suas atividades**
- **Setor SUAP: DENS do campus que ele irá atuar**

**Ao final, clique no botão "Salvar" .**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-07/fN6cBOH0EJZX7rgI-captura-de-tela-de-2025-07-18-15-38-08.png)

> Atenção: Descrição: Configure todos os parâmetros da ocupação, incluindo período de atuação e setor de lotação.

**-----------------------------------------------------------------------------------------------------------------------------------**

### **9º PASSO** - Processo Finalizado

**Agora o Professor Prestador está com um setor associado e poderá desenvolver suas atividades no sistema.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-07/CnNFasfdYVk1zLJk-captura-de-tela-de-2025-07-18-15-43-20.png)

> Atenção: Descrição: O processo de cadastro e vinculação foi concluído com sucesso. O professor prestador já pode acessar as funcionalidades do sistema.

**-----------------------------------------------------------------------------------------------------------------------------------**

## **Observações Importantes**

> Erro: Certifique-se de ter todas as informações necessárias antes de iniciar o processo Mantenha os dados atualizados para garantir a precisão das informações

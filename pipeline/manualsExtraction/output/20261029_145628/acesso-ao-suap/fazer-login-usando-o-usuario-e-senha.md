# Fazer Login Usando o Usuário e Senha

> Informação: O passo a passo para fazer o processo de autenticação do usuário no sistema SUAP

**1º PASSO : Dependendo do caso, o usuário vai ser o SIAPE para o servidor, MATRÍCULA no caso do aluno e o CPF para os terceirizados, bolsistas e afins.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-02/0DbkbRGf0zACujlU-01.png)

**2º PASSO : O processo de autenticação sendo bem-sucedido. O acesso às funcionalidades do sistema será liberado da forma apresentada na tela abaixo, constando no menu esquerdo a foto com o nome do usuário logado e o link " SAIR " para fechar a sessão.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-02/3w5IUysgtzjXnPvU-02.png)

> Erro: Caso apareça uma tela com uma mensagem de erro, o usuário deverá rever: - A senha ou usuário estão errados; - O usuário não está cadastrado no sistema; - O usuário está inativo ou sem permissões de acessar o sistema;

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-02/eOOlUuQGKsELHz2j-03.png)

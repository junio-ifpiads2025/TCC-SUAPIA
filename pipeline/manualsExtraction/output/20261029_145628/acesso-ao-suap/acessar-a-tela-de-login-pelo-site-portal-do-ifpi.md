# Acessar a Tela de Login pelo Site/Portal do IFPI

> Informação: O primeiro passo é saber o caminho para acessar o sistema SUAP. Pelo site do IFPI é possível encontrar o link que leva ao sistema.

**1º PASSO : Procurando a palavra IFPI no Google, o site do instituto aparece na primeira posição da lista de resultados.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-02/cMxcwcw2zfWZmxcQ-01.png)

**2º PASSO : Digitando " ifpi.edu.br " na barra de endereços. Tem-se o acesso direto ao site do IFPI.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-02/q97Y1KIH0BbMyHrx-02.png)

**3º PASSO : Navegando pelo menu esquerdo do site até a parte área do servidor, encontra-se o Link " SUAP " que leva ao sistema.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-02/UQalRdCjF84NgSSk-03.png)

**4º PASSO : Para acessar o sistema SUAP é necessário estar autenticado.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2025-02/UhCwjN1EOJvMSBBv-04.png)

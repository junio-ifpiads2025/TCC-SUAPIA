# Reservar Refeição com Acesso a Conta do Suap

1. Acesse sua conta do suap

   ![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-05/SOwthTN95AGha6OP-image.png)
2. Acesse o menu: **ATIVIDADES ESTUDANTIS - Restaurante Institucional - Reservar Refeições**

   ![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-05/LiYHo46bzBiURSmy-image.png)
3. Clique no botão **Reservar** da refeição disponível para reserva **Nota:** Para que a reserva seja realizada com sucesso é necessário atender os requisitos abaixo:           - Aluno precisa está matriculado           - A quantidade de reservas não podem ser igual a quantidade da refeição liberada           - Aguarde o início das reservas           - Reservar antes do horário de encerramento das reservas

   ![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-05/BBJohS5riEfiNKRX-image.png)
4. Reserva realizada com sucesso

   ![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-05/Wjzcjaq1fJc5zLoR-image.png)

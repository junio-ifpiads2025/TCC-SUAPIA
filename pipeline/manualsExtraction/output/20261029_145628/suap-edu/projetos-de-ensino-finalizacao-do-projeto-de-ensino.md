# Projetos de Ensino - Finalização do Projeto de Ensino

> Informação: Caso o projeto não possua mais pendências, o mesmo pode ser finalizado pelo coordenador do projeto. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/qsSRla7MEZ5ubaGV-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/pc5yracO4kX4DQIy-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/xBZhX21LDwYo4WR6-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/kj8F5en2fBBBnkC0-image.png)

**5º PASSO: Clico no botão "Finalizar Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/MKoMpESRAlAjMlx0-image.png)

**6º PASSO: Vejo mensagem de sucesso "Conclusão finalizada com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/k4zljlz5u5mKNEm5-image.png)

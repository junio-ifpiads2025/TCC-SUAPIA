# Cadastro das Fotos

> Informação: Cadastro das fotos que ilustram as atividades executadas no projeto. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/KyEILjuczihGbGJc-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/g3hYlTgWtVaCd5sp-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/jr0ufUNW7JJ5vUUe-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/rsYAynechArwtae1-image.png)

**5º PASSO: Clico na aba "Fotos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/oLbRayC3zhs2nt25-image.png)

**6º PASSO: Clico no botão "Adicionar Foto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/4aRlFLIlePpozfI1-image.png)

**7º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/ZwvNbKUOFwzOzJ47-image.png)

**8º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/WMAesEJxWy4dtE35-image.png)

**9º PASSO: Vejo mensagem de sucesso "Foto adicionada com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/5udPyQZLiz8dn6tY-image.png)

# Cadastro de Anexo do Projeto

> Informação: Cadastro de documento diverso relacionado ao projeto. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/MdhQmyl44Q16yLer-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Y0YDHhu4exOmtlIV-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/qXGuWMFhe3STJGlb-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/c0CgyzuiGhkWYaWZ-image.png)

**5º PASSO: Clico na aba "Anexos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/se8t9qVJWejNglV5-image.png)

**6º PASSO: Clico no botão "Adicionar Anexo"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/fttSVteNW996eCTx-image.png)

**7º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/YxRwuYcFiK5SstZ6-image.png)

**8º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/BTzaDkZ7xBjeW6rR-image.png)

**9º PASSO: Vejo mensagem de sucesso "Anexo cadastrado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/ujVhnv2wSXreBgV3-image.png)

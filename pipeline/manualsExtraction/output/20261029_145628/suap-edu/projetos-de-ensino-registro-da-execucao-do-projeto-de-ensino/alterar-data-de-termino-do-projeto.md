# Alterar data de término do projeto

> Informação: Permite a atualização da data de término prevista do projeto. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/w4oRMOJQD6SosqP0-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/wYVa1xNlkFHNAP6s-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Gmemxj0coow2qUzy-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/oJwQUDspVqQhEGhV-image.png)

**5º PASSO: Clico na aba "Dados do Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/0DW5pacL8uaOba4o-image.png)

**6º PASSO: Clico no botão "Editar Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/7gSpyXsn4XwvkqKi-image.png)

**7º PASSO: Vejo a página "Editar Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/YlRhhjUtbkGvwbhu-image.png)

**8º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/GZfyxh2OGggHsdQo-image.png)

**9º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/zCkgfL4o6smkKqVt-image.png)

**10º PASSO: Vejo mensagem de sucesso "Projeto editado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/TktF5HugMP0vFXru-image.png)

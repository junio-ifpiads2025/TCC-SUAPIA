# Cadastro dos Beneficiários Atendidos

> Informação: Durante a execução do projeto, o coordenador irá registrar a quantidade de pessoas e de instituições que foram efetivamente beneficiadas pelo projeto. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/xYgMvVsZmSiAyEEW-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/rmVVDZv6JlBiAZbE-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/xodBCsva12jTWIo3-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/1bAIlHEDVS0j8cD6-image.png)

**5º PASSO: Clico na aba "Caracterização dos Beneficiários"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Kcw9GafTMQxsXiYF-image.png)

**6º PASSO: Olho a linha "Movimentos Sociais"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/6e24Pt0aIUZkrHvY-image.png)

**7º PASSO: Clico no botão "Registrar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/jakwcizYOKQzTLfW-image.png)

**8º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/9Gd3IKrtMfcn0gyS-image.png)

**9º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/T309kjfWoGycsb7f-image.png)

**10º PASSO: Vejo mensagem de sucesso "Caracterização registrada com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/8Cs1q8snPkHa931c-image.png)

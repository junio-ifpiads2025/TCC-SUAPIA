# Tutorial de Publicação de Horários

> Informação: Objetivo: Este manual foi desenvolvido para orientar os servidores no processo de publicação de horários no sistema SUAP.

**1º PASSO: O servidor deve clicar em ENSINO -> Turmas e Diários -> Diários para ter acesso aos diários e publicar os horários para os docentes.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2023-11/Nf0OegL5lGZfPVVh-pu01.png)

**2º PASSO: Na página seguinte, o servidor poderá utilizar os filtros para efetuar a publicação dos horários. Neste exemplo, é utilizado o filtro de Campus, onde será selecionado um campus e, em seguida, clicará em Filtrar.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2023-11/zNVZHFlSDQGZdx5K-pu02.png)

**3º PASSO: Na página seguinte, o servidor poderá realizar as seguintes ações: 1- Marcar a caixa para selecionar mais de um diário; 2- Selecionar todos os diários desejados; 3- Clicar em "Ação"; 4- Escolher a opção "Publicar Horário".**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2023-11/Up8eBuGchyx5LBlI-pu03.png)

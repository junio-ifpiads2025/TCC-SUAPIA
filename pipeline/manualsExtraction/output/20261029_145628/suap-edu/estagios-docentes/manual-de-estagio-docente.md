# MANUAL DE ESTÁGIO DOCENTE

### **1. Introdução**

**O Estágio Docente é uma etapa obrigatória nos cursos de licenciatura, prevista na legislação educacional brasileira como componente curricular de formação prática. No âmbito do IFPI , esse processo é gerenciado pelo sistema SUAP (Sistema Unificado de Administração Pública), que centraliza todas as etapas, desde a configuração da matriz curricular até o encerramento do estágio, permitindo o acompanhamento em tempo real por todos os envolvidos.**

> Informação: Este manual apresenta o fluxo completo do Estágio Docente no SUAP, descrevendo as ações de cada perfil de usuário de forma clara e sequencial.

### **2. Objetivo**

**Orientar os usuários do SUAP — servidores da Secretaria Acadêmica, Supervisores de Estágio, Professores Orientadores, Coordenadores de Curso e Estudantes — sobre os procedimentos corretos para o registro, acompanhamento e encerramento do Estágio Docente no sistema.**

### **3. Público-Alvo**

**Este manual é destinado a:**

- **Secretaria Acadêmica : responsável pelo cadastro de turmas, diários e vinculação de estudantes;**
- **Supervisor de Estágio Docente : responsável pelo cadastro dos dados da escola e acompanhamento administrativo;**
- **Professor Orientador : responsável pelo acompanhamento pedagógico, registro de visitas e encerramento;**
- **Coordenador de Curso : responsável por vincular o coordenador de estágio docente ao curso;**
- **Estudante Estagiário : responsável pelo envio do portfólio (relatório final).**

### **4. Pré-requisitos**

**Antes de iniciar os procedimentos descritos neste manual, verifique se os seguintes itens estão devidamente configurados no SUAP:**

- **O componente de Estágio Docente está vinculado à matriz curricular com o tipo Prática Profissional e subtipo de estágio docente selecionado**
- **O Coordenador de Estágio Docente está vinculado ao curso no SUAP**
- **A turma e o diário do componente de estágio já foram criados pelo Controle Acadêmico**
- **Os estudantes estão matriculados e vinculados ao diário correspondente**

> Informação: Os estudantes somente aparecerão na tela de Estágios Docentes se estiverem devidamente vinculados ao diário. Caso não apareçam, verifique o vínculo com a Controle Acadêmico.

**Essa configuração é realizada no momento da criação da matriz curricular do curso de licenciatura. Após concluída, não precisa ser repetida.**

|  |  |
| --- | --- |
| **1º** | **Acessar a Matriz Curricular:** Ensino → Cursos, Matrizes e Componentes → Matrizes. Localize a matriz do curso e clique no ícone de edição. |

|  |  |
| --- | --- |
| **2º** | **Vincular o componente com o tipo correto:** Ao adicionar o componente de Estágio Docente, no campo Tipo selecione: Prática Profissional. |

|  |  |
| --- | --- |
| **3º** | **Configurar como Estágio Docente:** Com o tipo selecionado, o sistema exibirá o quadro de Estágio Docente. Marque: "É um Seminário de Estágio Docente?" e selecione o Tipo (Ex.: Estágio Docente I, II, III ou IV). |

### **11. Dúvidas Frequentes (FAQ)**

**O estudante não aparece na tela de Estágios Docentes. O que fazer? Verifique se o estudante está matriculado e vinculado ao diário do componente de estágio. Caso não esteja, a Secretaria Acadêmica deve realizar o vínculo.**

**O status está como "Cursando" mesmo após o encerramento. É correto? Sim. O status final de "Aprovado" só é atualizado após o fechamento do diário. Enquanto estiver aberto, o sistema exibirá "Cursando".**

**Posso encerrar o estágio sem o estudante ter enviado o portfólio? Para encerramento por conclusão, o portfólio é necessário. Para encerramento por não conclusão, ele não é exigido.**

**Quem pode registrar o encerramento do estágio? O encerramento do Estágio Docente pode ser registrado pelo Professor Orientador e/ou Professor da disciplina Estágio Supervisionado.**

**O que acontece se o estágio for em mais de uma escola? Utilize a opção "Adicionar Estágio Concomitante" disponível na tela de listagem. Para cada escola adicional, um novo formulário deve ser preenchido.**

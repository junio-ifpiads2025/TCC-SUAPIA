# Inclusão de Servidor na Equipe

> Informação: Cadastro do servidor membro do projeto de ensino. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/NyQ8fJRHoN6pmk8g-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/OOB43A4coAOvnmuP-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/jWMwCZeG0uASez6p-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/m1OmJDbMJd7Gj2yX-image.png)

**5º PASSO: Clico na aba "Equipe"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/AfQvV0NLqb5BvHvT-image.png)

**6º PASSO: Clico no botão "Adicionar Servidor"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/jNZB9q2PkrjOEcCp-image.png)

**7º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/aa0NMSqEMltTjpGo-image.png)

**8º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/BuknF3AKwKncYkzS-image.png)

**9º PASSO: Vejo mensagem de sucesso "Participante adicionado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/i5kUSBn8FbwaCHz5-image.png)

# Inclusão de Aluno na Equipe

> Informação: Cadastro do aluno membro do projeto de ensino. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/YqbPDj3kPUEQoJmd-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/mBdM419CNbBNZD1r-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/VXcmAyY3F3jZDxCF-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/cmDNbTISpRFZKxOd-image.png)

**5º PASSO: Clico na aba "Equipe"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/2nZ9lEmhuhSWY3SU-image.png)

**6º PASSO: Clico no botão "Adicionar Aluno"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/dQPUpUwzkRp9c0VM-image.png)

**7º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/eFQ9c1B5tkygCDbq-image.png)

**8º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/a2JGBO4iBdDprLuw-image.png)

**9º PASSO: Vejo mensagem de sucesso "Participante adicionado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/3tVrNgWQiasYtUo9-image.png)

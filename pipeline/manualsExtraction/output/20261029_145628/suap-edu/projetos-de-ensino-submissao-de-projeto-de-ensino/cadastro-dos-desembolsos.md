# Cadastro dos Desembolsos

> Informação: Com base na memória de cálculo, neste passo o coordenador do projeto informa quando pretende realizar os gastos(desembolsos) dos recursos. Por exemplo, uma memória de cálculo no valor de R$ 10.000,00 prevista para pagamento de alunos bolsistas pode ter 10 desembolsos, no valor de R$1.000,00 cada, que serão executados ao longo de 10 meses. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/kBO6nvoJakJX4ku9-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/EwYFZ4NXHgrfTDm4-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/XmDI8Vf9ddIQDqEv-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/N24tUzZ6o2aM79lO-image.png)

**5º PASSO: Clico na aba "Plano de Desembolso"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/4GYasbmBc5DNCX4Y-image.png)

**6º PASSO: Clico no botão "Adicionar Item"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/4GgAhAWf8UzY8oNQ-image.png)

**7º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/BxNuPutBKPUcymNx-image.png)

**8º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/W9xvWkyrla7waGkC-image.png)

**9º PASSO: Vejo mensagem de sucesso "Desembolso adicionado com sucesso."**

# Submissão do Projeto

> Informação: Após o cadastro de todas as informações obrigatórias, o coordenador do projeto está apto a realizar a submissão do projeto. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/3jXYzt5GoPguH9G2-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/EV5ZkQxf5WDTNucA-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/5viPn7JQyQu1WONB-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/b01gaONIRPWMv73r-image.png)

**5º PASSO: Clico no botão "Enviar Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/jyVPHCDFG10ShCwc-image.png)

**6º PASSO: Vejo mensagem de sucesso "Projeto enviado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/JGDxiV7baepQ5M4W-image.png)

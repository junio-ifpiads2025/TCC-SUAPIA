# Cadastro das Metas

> Informação: Cadastro das metas do projeto. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/XJmqsqrvg0pD6qio-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/1pduJ1wlZVgQZGH1-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/66RWf3sM0myFwC42-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/N49XKaA1BRirq2X1-image.png)

**5º PASSO: Clico na aba "Metas/Atividades"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/qJNfk5NzUadZ5Q6j-image.png)

**6º PASSO: Clico no botão "Adicionar Meta"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/jLRB7KdEnqe4T7Mw-image.png)

**7º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/HenwdXgMoP8fkE6E-image.png)

**8º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/LtZm6V9II38k1q2G-image.png)

**9º PASSO: Vejo mensagem de sucesso "Meta adicionada com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Lex97keFauj598yJ-image.png)

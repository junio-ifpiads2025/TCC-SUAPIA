# Cadastro do Projeto

> Informação: Formulário de submissão com as informações básicas do projeto. Após o envio dos dados, o projeto estará cadastrado mas ainda não terá sido submetido, ou seja, a situação do projeto será 'em edição' (rascunho). Só após o cadastro das demais informações obrigatórias, descritas nos próximos passos, é que o projeto poderá ser efetivamente submetido. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Submeter Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/7GZddRmxncH63QIc-image.png)

**2º PASSO: Vejo a página "Editais de Ensino e de Fluxo Contínuo com Inscrições Abertas"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/L9SxZkh9aODNhU6B-image.png)

**3º PASSO: Clico no botão "Adicionar Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/mQQklLRpb7gBZ73y-image.png)

**4º PASSO: Vejo a página "Adicionar Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/g6pREGBxQBaEHjeq-image.png)

**5º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/F2v94bof3GVYDCp2-image.png)

**6º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/VIsew05xaKntxLEq-image.png)

**7º PASSO: Vejo mensagem de sucesso "Projeto cadastrado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/zVL1Em1ZOISatay3-image.png)

# Cadastro das Atividades

> Informação: Cadastro das atividades que serão realizadas dentro de cada meta do projeto. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/fcMQH0Q7MrSbqm6w-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/k7U95LrcKohhQLBt-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/sfgeQU2EN4uJIRea-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/WcF8tyKJBTXsK0J4-image.png)

**5º PASSO: Clico na aba "Metas/Atividades"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/730zhi74eLFileQH-image.png)

**6º PASSO: Clico no botão "Adicionar Atividade"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/zHjEQ3zDKo7A1zhi-image.png)

**7º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/GGcO48sFf5fnfz1e-image.png)

**8º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/DJnJeWOBhpupAn0n-image.png)

**9º PASSO: Vejo mensagem de sucesso "Atividade adicionada com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/vR6NH7ACnClJPaL3-image.png)

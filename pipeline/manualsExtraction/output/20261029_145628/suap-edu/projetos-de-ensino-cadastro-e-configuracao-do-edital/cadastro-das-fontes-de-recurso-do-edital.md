# Cadastro das Fontes de Recurso do Edital

> Informação: O valor informado deverá ser o máximo que cada projeto aprovado poderá gastar na respectiva despesa(rubrica). Este valor servirá como base para o coordenador do projeto definir a memória de cálculo e o plano de desembolso. Ação executada pelo Gerente Sistêmico de Projetos de Ensino ou Coordenador de Projetos de Ensino.

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Editais :: Gerenciar Editais"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/NkKp5Elhp2MSGOr3-image.png)

**2º PASSO: Vejo a página "Editais"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/GFhhiQsBBulgO90A-image.png)

**3º PASSO: Olho para a listagem**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/fumhA6mZqgDLLRHG-image.png)

**4º PASSO: Olho a linha "Nome do edital"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/K2MN1jxlwQiSk8LG-image.png)

**5º PASSO: Clico no ícone de exibição**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/TpMMpbnOxTM2TMwS-image.png)

**6º PASSO: Vejo a página "Nome do edital - Edital de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/wToiaFagG1HoYX0V-image.png)

**7º PASSO: Clico na aba "Fonte de Recursos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/v4PaxeqgsABb0SnL-image.png)

**8º PASSO: Clico no botão "Adicionar Recurso"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/onW972zwE52WoNae-image.png)

**9º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/aF8XPCqyXnn2Ex4B-image.png)

**10º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/ssi5uenWnlyjy5Rg-image.png)

**11º PASSO: Vejo mensagem de sucesso "Recurso adicionado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/mkyLo9uPUeuMlJhz-image.png)

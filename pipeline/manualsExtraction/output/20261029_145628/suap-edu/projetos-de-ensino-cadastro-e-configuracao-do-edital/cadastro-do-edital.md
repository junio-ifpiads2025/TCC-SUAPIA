# Cadastro do Edital

> Informação: Cadastro do edital para seleção de projetos de ensino. Ação executada pelo Gerente Sistêmico de Projetos de Ensino ou Coordenador de Projetos de Ensino.

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Editais :: Gerenciar Editais"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/M1o6Z6bXYV1lx1BN-image.png)

**2º PASSO:** **Vejo a página "Editais"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/CRPFKQ7eERZfNWtq-image.png)

**3º PASSO:** **Clico no botão "Adicionar Edital"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/9dl03Q55JzX3Uuic-image.png)

**4º PASSO:** **Vejo a página "Adicionar Edital"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/7MozG1RnWkaI3PmG-image.png)

**5º PASSO:** **Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/LGQcKaXrxWKgnRnl-image.png)

**6º PASSO:** **Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/XrQEE4xpgHLebdJ3-image.png)

**7º PASSO:** **Vejo mensagem de sucesso "Edital cadastrado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/ir9XSAujuIGT70JS-image.png)

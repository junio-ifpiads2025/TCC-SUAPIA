# Projetos de Ensino - Validação da Conclusão do Projeto de Ensino

> Informação: O registro da conclusão do projeto precisa ser validado pelo monitor do mesmo. Ação executada pelo Monitor do Projeto (servidor).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Monitoramento"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/2nblkimeYcEvKnWS-image.png)

**2º PASSO: Vejo a página "Monitoramento"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/g0qCAA8JdKzWjfHL-image.png)

**3º PASSO: Olho a linha "Título do projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/TTFxvnAg34fY33mL-image.png)

**4º PASSO: Clico no botão "Acompanhar Validação"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/PuIHS8CLCMR026Oy-image.png)

**5º PASSO: Vejo a página "Validar Execução"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/2f7uKoctOXWWNeQ7-image.png)

**6º PASSO: Clico na aba "Conclusão do Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/2YsTKStMqhCJU8wL-image.png)

**7º PASSO: Clico no botão "Emitir Parecer"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Vupo8Fd44B55myQq-image.png)

**8º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/lv1RSUcT8GZUtYia-image.png)

**9º PASSO: Clico no botão "Enviar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/vprpndnHgbnHgf09-image.png)

**10º PASSO: Vejo mensagem de sucesso "Conclusão do projeto registrada com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/d8Zwu8lZZBUecFWV-image.png)

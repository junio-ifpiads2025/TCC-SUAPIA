# Manual coordenador para Avaliação de AC e ATPA

## Manual para coordenador analisar as solicitações de ATPA e AC

> Informação: Para acessar a Resolução Normativa nº 166/2023  click no link: ifpi.edu.br/166-2023 Para acessar a Resolução Normativa nº 163/2023  click no link: ifpi.edu.br/163-2023

**1º PASSO: Na página inicial, o coordenador para analisar uma AACC, precisa clicar no quadro " COORDENAÇÃO DE CURSO ".**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2023-03/5ZO9IcP5gulaq6bE-coor-1.png)

**1.1º PASSO: Na página inicial, o coordenador para analisar uma ATP, precisa clicar no quadro " COORDENAÇÃO DE CURSO ".**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2023-03/cILmaAQfInLhCkdp-coor-6.png)

> Informação: Os passos seguintes são os mesmos tanto para ATP quanto para AACC.

**2º PASSO: Na página seguinte de Atividades de Aprofundamento, aparecerão as solicitações dos discentes aguardando análise pelo coordenador. Para acessar uma solicitação, o coordenador irá clicar no ícone de lupa para deferir ou indeferir.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2023-03/VAB8Os3WniQw5U0H-coor-2.png)

**3º PASSO: na página de Atividades de Aprofundamento e/ou Atividades complementares, o coordenador irá avaliar a solicitação do discente e clicar no botão " Deferir " caso aprove ou " Indeferir " caso indefira.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2023-03/Ws5pfGLK78TWU4dC-coor-3.png)

**4º PASSO: Ao clicar em " Deferir ", a solicitação do discente será aprovada e sairá da caixa de espera. Porém, se a avaliação for o " Indeferimento ", o coordenador precisará justificar sua decisão no campo "Razão do Indeferimento" e, em seguida, clicar no botão " Salvar ".**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2023-03/b8reWVkv9LUJakQf-coor-4.png)

**5º PASSO: Caso seja necessário, o indeferimento pode ser desfeito pelo coordenador, clicando no botão Cancelar Indeferimento.**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2023-03/xagN7FN3mC6Ph0Yd-coor-5.png)

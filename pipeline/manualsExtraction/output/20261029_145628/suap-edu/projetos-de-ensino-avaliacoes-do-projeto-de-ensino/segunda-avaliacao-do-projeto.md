# Segunda Avaliação do Projeto

> Informação: O avaliador indicado realiza a avaliação do projeto. Ação executada pelo Avaliador do Projeto (servidor ou avaliador externo à instituição).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Avaliar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/o2OhKCrEReOuK2N4-image.png)

**2º PASSO: Vejo a página "Editais em Avaliação"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/AgCjCFo0riWnwO8v-image.png)

**3º PASSO: Olho a linha "Nome do edital"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/ceWnGbNATDq4zkda-image.png)

**4º PASSO: Clico no link "CZN"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/HizfXrTavdFsmczn-image.png)

**5º PASSO: Vejo a página "Seleção de Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/93Z44b8tI518so0m-image.png)

**6º PASSO: Olho a linha "Título do projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/jL1Y5VcmvnaTNs0t-image.png)

**7º PASSO: Clico no botão "Avaliar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/naRGqz4r3SkFbYYG-image.png)

**8º PASSO: Vejo a página "Avaliação de Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/mN6zfpeOiNP7O74o-image.png)

**9º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/gjwfODFP96p6XNQ3-image.png)

**10º PASSO: Clico no botão "Enviar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/ZH92c9zbIwNhxyUZ-image.png)

**11º PASSO: Vejo mensagem de sucesso "Projeto avaliado com sucesso."**

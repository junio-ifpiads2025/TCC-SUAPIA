# Primeira Avaliação do Projeto

> Informação: O avaliador indicado realiza a avaliação do projeto. Ação executada pelo Avaliador do Projeto (servidor ou avaliador externo à instituição).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Avaliar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/flvXKnzNF9F1ScS0-image.png)

**2º PASSO: Vejo a página "Editais em Avaliação"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Hx9DNWx2p7QVf7XU-image.png)

**3º PASSO: Olho a linha "Nome do edital"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/1HAgI5stIB3hvVB6-image.png)

**4º PASSO: Clico no link "CZN"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/F24HGZq3KwlRXRqK-image.png)

**5º PASSO: Vejo a página "Seleção de Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/JjOCIkgciBM51EZe-image.png)

**6º PASSO: Olho a linha "Título do projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/kBeI8yHsExycf7GT-image.png)

**7º PASSO: Clico no botão "Avaliar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/u0E4uRMCRFpdOizM-image.png)

**8º PASSO: Vejo a página "Avaliação de Projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Pz1y5Xiova3YGOn7-image.png)

**9º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/pfxytoRIYpbPddXM-image.png)

**10º PASSO: Clico no botão "Enviar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Alcqd7ueCtioqX57-image.png)

**11º PASSO: Vejo mensagem de sucesso "Projeto avaliado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/F9brluN42pB1nOV1-image.png)

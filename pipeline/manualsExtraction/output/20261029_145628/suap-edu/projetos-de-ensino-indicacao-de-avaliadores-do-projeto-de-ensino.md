# Projetos de Ensino - Indicação de Avaliadores do Projeto de Ensino

> Informação: Dentre todos os avaliadores cadastrados na comissão de avaliação do edital, é necessário, para cada projeto pré-selecionado, indicar quais irão avaliar cada projeto. Ação executada pelo Gerente Sistêmico de Projeto de Ensino ou Coordenador de Projeto de Ensino.

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Indicar Avaliador"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/VHX4DJ6EXFn2Jthf-image.png)

**2º PASSO: Vejo a página "Editais em Avaliação"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/CWgfxqzpmW4AzZZt-image.png)

**3º PASSO: Olho a linha "Nome do edital"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/a2BF9umxLnGvAB5i-image.png)

**4º PASSO: Clico no ícone de exibição**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/fJvi9DEGmZ9nVQ3A-image.png)

**5º PASSO: Vejo a página "Selecionar Avaliadores dos Projetos do Nome do edital"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/9JQnYjzqZw9TbMqh-image.png)

**6º PASSO: Olho a linha "Título do projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/vw713U1LU6ZSzTc8-image.png)

**7º PASSO: Clico no botão "Selecionar Avaliadores"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/BqkuTxBBmDnI4aRw-image.png)

**8º PASSO: Vejo a página "Indicar Avaliadores do Projeto Título do projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/6xLzbpBihF9wLmcL-image.png)

**9º PASSO: Clico no botão "Enviar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/8KBjyFFh251DasF2-image.png)

**10º PASSO: Vejo mensagem de sucesso "Avaliadores cadastrados com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/anAW57A5Pc7tczOO-image.png)

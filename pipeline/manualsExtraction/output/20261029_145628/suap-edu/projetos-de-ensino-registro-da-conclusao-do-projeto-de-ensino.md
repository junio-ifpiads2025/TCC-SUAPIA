# Projetos de Ensino - Registro da Conclusão do Projeto de Ensino

> Informação: Após o preenchimento de todos os dados sobre a execução do projeto, o coordenador do projeto pode registrar a conclusão do mesmo. Ação executada pelo Servidor (coordenador do projeto).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/L0XDX4lQDJR9Hmeu-image.png)

**2º PASSO: Vejo a página "Meus Projetos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/7SCMqwFgOlFHCHYs-image.png)

**3º PASSO: Clico no botão "Visualizar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Vtskw2PZn6Y3JWAo-image.png)

**4º PASSO: Vejo a página "Projeto de Ensino"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/p2eHmXIw8Kcggy9S-image.png)

**5º PASSO: Clico na aba "Conclusão"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/aqnqbKBWU5pYrgpJ-image.png)

**6º PASSO: Clico no botão "Registrar Conclusão"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/X2CyT5W1WtnKk3Y9-image.png)

**7º PASSO: Preencho o formulário com os dados**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/U7FSWTWC80xP50Nq-image.png)

**8º PASSO: Clico no botão "Salvar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/a2CxQKTtHI8WCed7-image.png)

**9º PASSO: Vejo mensagem de sucesso "Conclusão do projeto registrada com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/5K6Bwb8PG2jdOmQW-image.png)

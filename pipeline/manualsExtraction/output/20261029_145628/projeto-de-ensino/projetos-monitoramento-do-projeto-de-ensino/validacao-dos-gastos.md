# Validação dos Gastos

> Informação: Cada registro de gasto deve ser validado pelo monitor do projeto. Por padrão, o monitor do projeto será o coordenador de extensão que fez a pré-seleção. O monitor do projeto poderá ser alterado no menu Ensino -> Projeto -> Gerenciar Monitores. Ação executada pelo Monitor do Projeto (servidor).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Monitoramento"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/uwaFCEvgit5bKuSx-image.png)

**2º PASSO: Vejo a página "Monitoramento"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/uDifzP2P8tLBbcDF-image.png)

**3º PASSO: Olho a linha "Título do projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/3c6uhcWpqldTdBVz-image.png)

**4º PASSO: Clico no botão "Acompanhar Validação"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Q2UGN1lCJ9x6SDjn-image.png)

**5º PASSO: Vejo a página "Validar Execução"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/37KE76fNfArVrd8b-image.png)

**6º PASSO: Clico na aba "Gastos"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Yz6ddDInILcSCQMh-image.png)

**7º PASSO: Olho a linha "Obs sobre o registro do gasto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/CL15wftUXCfUF0k9-image.png)

**8º PASSO: Clico no botão "Aprovar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/87nvkyPufhefO9MM-image.png)

**9º PASSO: Vejo mensagem de sucesso "Gasto validado com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/tdo1jQ43FEQKyqc2-image.png)

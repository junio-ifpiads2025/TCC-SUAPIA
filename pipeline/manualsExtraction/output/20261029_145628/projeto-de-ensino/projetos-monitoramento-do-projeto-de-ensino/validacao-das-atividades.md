# Validação das Atividades

> Informação: Cada registro de execução de atividade deve ser validado pelo monitor do projeto. Por padrão, o monitor do projeto será o coordenador de extensão que fez a pré-seleção. O monitor do projeto poderá ser alterado no menu Ensino -> Projeto -> Gerenciar Monitores. Ação executada pelo Monitor do Projeto (servidor).

**1º PASSO: Acesso o menu "Ensino :: Projetos :: Monitoramento"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/oO8J7xo26BO4RQEe-image.png)

**2º PASSO: Vejo a página "Monitoramento"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/RhgpE6HgXhX9H8Hd-image.png)

**3º PASSO: Olho a linha "Título do projeto"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/CzRnAvdyZgshTL9z-image.png)

**4º PASSO: Clico no botão "Acompanhar Validação"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/U8xssrSqI1S5pImd-image.png)

**5º PASSO: Vejo a página "Validar Execução"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/chWwZTztWL19es3v-image.png)

**6º PASSO: Clico na aba "Metas"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/carGgIqwdqadHd3o-image.png)

**7º PASSO: Olho a linha "Descrição da Atividade 1"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/lH19owxFTQIyCOj1-image.png)

**8º PASSO: Clico no botão "Aprovar"**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/aDpFBs4GGJv5PtJ7-image.png)

**9º PASSO: Vejo mensagem de sucesso "Execução de atividade validada com sucesso."**

![captura de tela](https://manuais.ifpi.edu.br/uploads/images/gallery/2024-02/Bp3o3BfmLJmvyrFB-image.png)
